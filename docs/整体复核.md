# 整体复核（产品 / 体验 / 安全 / 算法 / 企业级 / 演进 / 实施 / 运维）

复核对象是 HYX-KMS-PY 当前源码、本地测试实例、回归结果与运维文档。Codex Security 的一次标准扫描快照返回零个已确认发现，但覆盖状态为部分完成且未封存；后续版本、默认端口、测试和文档另有变化，因此该快照不能作为当前最终源码的完整安全验收结论。

当前结论：单机测试实例的主要功能、失败关闭、资源准入和数据恢复工具已经成形；生产可用性、真实设备、RPO/RTO、高可用和商业交付尚未验收。不能把本地回归通过等同于生产就绪。

## 产品与体验

- 网站品牌为「密钥管理服务平台」，导航为首页、激活、产品、使用说明，许可证入口保留在页脚右侧；导航品牌区使用站点 SVG Logo，浏览器标签页同时使用该图标和统一服务名称。
- 产品按 Windows、Windows Server、Office 分类；发行分组从新到旧排列；Office 提供 32/64 位架构选择。
- 界面支持简体中文、繁體中文、English、日本語、Français，手动选择优先于浏览器语言并保存。
- KMS 默认地址和端口收在高级设置中；默认值清楚展示，仅管理员使用自定义端口时需要修改。
- 复制/下载失败会清除成功状态；脚本生成对主机、端口和产品标识做校验，阻断命令注入。
- 站点只展示目录与生成脚本，不会在服务器执行激活命令；下载脚本本身不产生客户端记录。
